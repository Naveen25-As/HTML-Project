# Laundry Services Hero Section

## About

This project is a simple Laundry Services webpage created using HTML and CSS.

The main purpose of this assignment is to understand how `display: inline-block` can be used to create layouts without using Flexbox.

## Features

- Laundry Services navbar
- Logo on the left
- Navigation links
- User name on the right
- Two-column hero section
- Laundry-related image
- Service booking button
- Inline-block layout

## CSS Concepts Used

- `display: inline-block`
- `width`
- `vertical-align`
- `padding`
- `margin`
- `background`
- CSS gradient
- Border radius

## How to Run

1. Keep all files in the same folder.
2. Add a laundry-related image and name it `laundry.jpg`.
3. Open `index.html` in a browser.
