# Viewport Units and Box Model Assignment

## Objective

This assignment demonstrates the use of viewport units and the CSS box model.

## Requirements Implemented

- A single `div` is used as the main container.
- The container has:
  - `25vw` left and right spacing.
  - `10vh` top and bottom spacing.
- An image is placed inside the `div`.
- A button is placed below the image.
- The button uses a gradient background.
- Padding and border demonstrate the CSS box model.
- `box-sizing: border-box` is used to control the element's dimensions.

## CSS Concepts Used

### Viewport Units

- `vw` represents a percentage of the viewport width.
- `vh` represents a percentage of the viewport height.

The container uses:

```css
margin: 10vh 25vw;
````

This creates:

* 10% viewport height spacing at the top and bottom.
* 25% viewport width spacing on the left and right.

### Box Model

The container demonstrates:

* Content
* Padding
* Border
* Margin
